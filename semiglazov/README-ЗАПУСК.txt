ЗАПУСК СИСТЕМЫ «АНАЛИТИКА ЭФФЕКТИВНОСТИ» (ФАВОРИТ ДИВАН)
================================================================

1. САМЫЙ БЫСТРЫЙ СПОСОБ (без OpenServer)
----------------------------------------------------------------
   Двойной клик по start.bat → откроется браузер:
   http://127.0.0.1:8082/analytics.php

   Скрипт сам находит PHP (в том числе в модулях OpenServer Panel 6),
   проверяет драйверы баз данных и поднимает встроенный сервер.
   Черное окно — это сервер. Закрыть окно = остановить сайт.
   Если порт занят, поменяйте в start.bat строку set "PORT=8082".

2. ЧЕРЕЗ OPENSERVER PANEL 6 (подробно — README-OPENSERVER.md)
----------------------------------------------------------------
   1. Скопируйте папку проекта целиком в  C:\OSPanel\home\semiglazov
      Важно: вместе со скрытой папкой .osp (в ней project.ini — по ней
      панель 6-й версии и находит проект).
   2. Включите модули: PHP-8.4 и (по желанию) MySQL-8.4,
      затем перезапустите панель.
   3. Откройте http://semiglazov.local/install.php — база создастся сама.
   4. Дашборд: http://semiglazov.local/analytics.php
      (адрес задаётся секцией [semiglazov.local] в .osp/project.ini)

   OpenServer 5: скопируйте папку в OpenServer\domains\favorit
   и откройте http://favorit/install.php

   MySQL:
     - база favorit_db создаётся автоматически, импорт не нужен;
     - сервер MySQL определяется сам: 127.0.0.1:3306, имена модулей
       MySQL-8.4 / MySQL-8.0 из hosts, порты 3306-3308;
     - свои параметры (пароль root) — в config.local.php или config.php;
     - полный дамп базы лежит в database/favorit_db.sql — его можно
       импортировать в phpMyAdmin вручную;
     - подробная инструкция — файлы БАЗА-ДАННЫХ.txt и README-OPENSERVER.md.
   Если MySQL недоступен, система сама переключится на SQLite:
     - файл базы: data/favorit.sqlite (или папка из FAVORIT_DATA_DIR);
     - схема и демо-данные создаются автоматически, цифры те же.

   Проверка окружения (PHP, драйверы PDO, MySQL, права на папку data):
     http://semiglazov.local/check.php  — работает даже без базы данных.

4. ЧТО ЕСТЬ В СИСТЕМЕ
----------------------------------------------------------------
   Дашборд          — 4 KPI, мини-графики, сводный график,
                      блок «Что видно по данным», прогноз выручки,
                      топ-5 продуктов, структура каналов.
   Заказы           — добавление, редактирование, удаление,
                      смена статуса, просрочка.
   Производство     — выпуск, брак, часы, себестоимость,
                      добавление и редактирование записей.
   Качество         — брак по причинам, потери, закрытие случаев.
   Финансы          — выручка, себестоимость, прибыль, рентабельность.
   Продажи          — заказы, средний чек, каналы.
   Каналы           — план/факт, CAC, конверсия.
   Кадры            — штат, ФОТ, приём и увольнение.
   Отчёты           — сводная таблица, CSV, планы, журнал действий.
   Справочник       — категории, продукция, цены.
   Данные           — источники данных, пользователи, роли,
                      пересоздание демо, бэкап SQL.

5. РЕДАКТИРОВАНИЕ ДАННЫХ
----------------------------------------------------------------

   Откроется форма с заполненными полями → «Сохранить изменения».
   Дашборд пересчитывается сразу.

9. ТРЕБОВАНИЯ
----------------------------------------------------------------
   PHP 8.0+ (проверено на 8.4): достаточно расширения pdo_sqlite,
   pdo_mysql — для работы на MySQL. Браузер.
   Внешние библиотеки и интернет не нужны.

   Если в PHP не включено ни одно расширение баз данных, сайт покажет
   понятную страницу с инструкцией (check.php), а не «белый экран».
