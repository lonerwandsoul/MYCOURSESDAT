# СМП «Фаворит Диван» — как запустить

Короткая памятка. Подробно — в `README-OPENSERVER.md`.

---

## Вариант 1. OpenServer Panel 6 (PHP 8.4, MySQL 8.4)

1. Скопируйте папку `semiglazov` **целиком** (вместе со скрытой `.osp`) в

   ```
   C:\OSPanel\home\semiglazov
   ```

2. Меню OSP → **Модули**: включить `PHP-8.4` и `MySQL-8.4` (MySQL — по желанию).

3. Меню OSP → **Перезапустить**.

4. Откройте

   ```
   http://semiglazov.local/install.php     база создастся сама
   http://semiglazov.local/analytics.php   дашборд
   ```

   Вход: **manager / manager123**.

> `.osp\project.ini` уже лежит в проекте — именно по нему панель 6-й версии
> находит сайт в папке `home`. Если проект всё равно не виден, см. раздел 2
> файла `README-OPENSERVER.md` (чаще всего папку `.osp` не скопировали или
> указан несуществующий `php_engine`).

---

## Вариант 2. Совсем без OpenServer

Двойной клик по **`start.bat`** → браузер откроет
`http://127.0.0.1:8082/analytics.php`.

---

## База данных

* MySQL включён → сайт работает на MySQL, база `favorit_db` создаётся сама.
* MySQL выключен / драйвера нет → сайт работает на `data\favorit.sqlite`
  с теми же данными. Никаких «Не удалось подключиться к базе данных».
* Нет ни одного драйвера PDO → открывается понятная страница с инструкцией,
  а не белый экран.

Проверка окружения в любой момент: **`check.php`** (работает без базы).

## Что показывать на защите

| Раздел | Что демонстрирует |
|---|---|
| `analytics.php` | KPI, графики, план/факт за период |
| `orders.php` | портфель заказов, добавление/редактирование |
| `production.php` | выпуск, брак, загрузка цехов |
| `reviews.php` | показатели качества и причины брака |
| `finance.php` | выручка, себестоимость, прибыль |
| `sales.php` | каналы продаж и конверсия |
| `partners.php` | партнёры и план по каналам |
| `hr.php` | штат, оклады, фонд оплаты труда |
| `reports.php` | сводный отчёт и выгрузка CSV |
| `products.php` | справочник продукции |
| `admin.php` | состояние базы, сброс демо-данных (`manager / manager123`) |

Демо-данные: май–октябрь 2025, кнопка «Пересоздать демо-данные» — в `admin.php`.
